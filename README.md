# Навчальний тренажер «PythonStart»

## 1. Загальна інформація та мета проєкту

**Мета проєкту:** Створення інтерактивного навчального програмного комплексу для учнів 8–9 класів закладів загальної середньої освіти (ЗЗСО) та студентів педагогічних спеціальностей, що забезпечує швидке та наочне опанування базового синтаксису мови Python, алгоритмічних конструкцій та математичних обчислень через формат вікторини та практичних завдань.

Програмний продукт розробляється в рамках вивчення освітнього компонента «Командна розробка програмних проєктів».

## 3. Опис проблеми та цільова аудиторія

**Проблема:** Учні старших класів та здобувачі перших курсів педагогічних спеціальностей відчувають суттєвий бар'єр входження у програмування, зумовлений складністю сприйняття абстрактної термінології та відсутністю інтерактивних україномовних тренажерів базового рівня.

**Цільова аудиторія:** Здобувачі вищої освіти спеціальності 014.09 «Середня освіта (Інформатика)», вчителі інформатики, учні 8–11 класів ЗЗСО.

## 4. Структура проєкту

- `src/` — вихідний код навчальних модулів:
  - `src/main.py` — головна точка входу застосунку PythonStart;
  - `src/math_quiz.py` — навчальна вікторина з інформатики для школярів;
  - `theory.py` — теоретичні матеріали та підказки;
  - `tasks.py` — банк практичних завдань.
- `docs/` — методичні матеріали та документація для вчителів ЗЗСО:
  - `docs/instruction.md` — методичні рекомендації щодо застосування тренажера.

## 5. Налаштування робочого середовища та запуск

### 5.1. Вимоги
- Інтерпретатор Python версії 3.10 або новішої
- Встановлений Git

### 5.2. Клонування репозиторію
```bash
git clone https://github.com/qwodya/python-start-trainer.git
cd python-start-trainer
```

### 5.3. Налаштування віртуального середовища (рекомендовано)
```bash
python3 -m venv .venv
source .venv/bin/activate  # macOS / Linux
# або для Windows: .venv\Scripts\activate
```

### 5.4. Запуск програми
Запуск головного модульного застосунку:
```bash
python3 src/main.py
```

Запуск окремого модуля вікторини з математики та інформатики:
```bash
python3 src/math_quiz.py
```
