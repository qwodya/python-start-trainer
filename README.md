# Навчальний тренажер «PythonStart»

## 1. Загальна інформація про проєкт

Програмний продукт розробляється в рамках вивчення освітнього компонента «Командна розробка програмних проєктів».  
Тренажер призначений для первинного засвоєння базових понять програмування мовою Python у формі інтерактивного діалогу.

## 3. Опис проблеми та цільова аудиторія

**Проблема:** Учні старших класів та здобувачі перших курсів педагогічних спеціальностей відчувають суттєвий бар'єр входження у програмування, зумовлений складністю сприйняття абстрактної термінології та відсутністю інтерактивних україномовних тренажерів базового рівня.

**Цільова аудиторія:** Здобувачі вищої освіти спеціальності 014.09 «Середня освіта (Інформатика)», вчителі інформатики, учні 8–11 класів ЗЗСО.

## 4. Структура програмного засобу

1. `main.py` – головний модуль запуску програми.
2. `theory.py` – модуль з теоретичними картками-підказками.
3. `tasks.py` – модуль з інтерактивними завданнями та перевіркою відповідей.

## 5. Інструкція із запуску

```bash
python3 main.py
```

## 6. MVP — Мінімально життєздатний продукт

**Увійде до першої версії:**
- Теоретичні картки з базових тем (змінні, умови, цикли)
- Інтерактивні завдання з перевіркою відповідей
- Статистика правильних відповідей за сесію

**Відкладено на майбутнє:**
- Авторизація та особистий кабінет
- Інтеграція з електронним журналом
- Графічний інтерфейс

## 7. Правила взаємодії команди

- Основний канал комунікації: API-запити + Telegram для живого учасника
- Усі домовленості фіксуються у git-комітах
- Час відповіді AI-учасників — 3–10 секунд (людини — до 12 годин)
- Нові функції — через Pull Request з code review від Claude 4.8 Opus
