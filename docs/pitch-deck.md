# Регламентний сценарій командного пітчу на Demo Day (5–7 хвилин)

## Слайд 1. Вступ та актуальність (1 хв)
- Представлення команди EduTech Innovators.
- Проблема: труднощі школярів 8–9 класів із абстрактним синтаксисом Python та відсутність миттєвого україномовного зворотного зв'язку.

## Слайд 2. Наше рішення — тренажер «PythonStart» (1 хв)
- Вебзастосунок із нульовим порогом входу, що працює з будь-якого пристрою.
- Модульна структура: теорія з кодом + інтерактивна вікторина + автоматична перевірка.

## Слайд 3. Жива демонстрація (Live Demo) (2 хв)
- Відкриття сайту в прямому ефірі за адресою https://qwodya.github.io/python-start-trainer
- Вибір теми «Змінні та типи даних», проходження вправи, демонстрація підказки про помилку та екрана підсумку.

## Слайд 4. Інженерні стандарти та надійність (1.5 хв)
- Модульна архітектура ES6, відмовостійкий REST API з Fallback, збереження в `localStorage`.
- Покриття тестами Vitest, автоматизований CI-конвеєр у GitHub Actions, версіонування за SemVer.

## Слайд 5. Підсумки та освітня перспектива (30 сек)
- Готовність до впровадження у курс інформатики ЗЗСО.
- Відповіді на запитання викладача та колег.
