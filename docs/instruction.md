# Методичні рекомендації щодо використання тренажера «PythonStart» у ЗЗСО

## 1. Цільове призначення
Навчальний тренажер розроблено для проведення практичних занять з інформатики у 8–9 класах закладів загальної середньої освіти (ЗЗСО).

## 2. Порядок запуску
Для запуску модулів програми використовуйте термінал:
```bash
python3 src/main.py
```
або окремий модуль вікторини:
```bash
python3 src/math_quiz.py
```
