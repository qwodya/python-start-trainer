# Реєстр звітів про дефекти (Bug Reports) та журнал Code Review у тренажері «PythonStart»

## 1. Звіт про дефект BUG-01: Некоректний розрахунок відсотка успішності при 0 запитаннях
- **Ідентифікатор:** BUG-01
- **Серйозність (Severity):** Medium
- **Пріоритет (Priority):** High
- **Компонент:** `src/js/quiz.js` -> `calculateScorePercentage()`
- **Опис дефекту:** Якщо користувач не відповів на жодне питання або загальна кількість дорівнює 0, виникало ділення на нуль, що повертало `NaN` замість числового значення 0%.
- **Кроки відтворення:** Викликати `calculateScorePercentage(0, 0)`.
- **Фактичний результат:** `NaN%` на підсумковому екрані.
- **Очікуваний результат:** `0%`.
- **Виправлення:** Додано захисну умову `if (!total || total === 0) return 0;`. Покрито тестом у `tests/quiz.test.js`.
- **Статус:** Закрито (Verified / Closed).

## 2. Звіт про дефект BUG-02: Чутливість до випадкових пробілів у відповідях учня
- **Ідентифікатор:** BUG-02
- **Серйозність (Severity):** High
- **Пріоритет (Priority):** High
- **Компонент:** `src/js/quiz.js` -> `validateAnswer()`
- **Опис дефекту:** Якщо учень випадково ввів пробіл перед чи після слова (наприклад `  float `), алгоритм зараховував помилку.
- **Виправлення:** Додано санітизацію рядків `String(selectedAnswer).trim().toLowerCase()`.
- **Статус:** Закрито (Verified / Closed).

## 3. Звіт про дефект BUG-03: Потенційна вразливість XSS при відображенні сторонніх даних API
- **Ідентифікатор:** BUG-03
- **Серйозність (Severity):** Critical (Security)
- **Пріоритет (Priority):** High
- **Компонент:** `src/js/ui.js`
- **Опис:** Вставка тексту цитати з API через `innerHTML` створювала загрозу XSS-атаки при компрометації зовнішнього сервера.
- **Виправлення:** Замінено на безпечне текстове поле або санітизацію тегів перед рендерингом.
- **Статус:** Закрито (Verified / Closed).
