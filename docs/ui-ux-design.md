# Специфікація UI/UX дизайну та прототипування навчального тренажера «PythonStart»

## 1. Загальна концепція та принципи проєктування
Дизайн навчального тренажера «PythonStart» орієнтований на учнів 8–9 класів ЗЗСО та студентів-початківців. Головні принципи:
- **Когнітивна простота:** мінімум візуального шуму, фокус на навчальному змісті та коді.
- **Миттєвий та дружній зворотний зв'язок:** чітке кольорове та текстове підтвердження дій учня без демотивуючих елементів.
- **Доступність (Accessibility):** високий контраст тексту (WCAG AA), великі клікабельні області для кнопок, адаптивність під смартфони.

## 2. Інформаційна архітектура (Sitemap) та User Flow
### 2.1. Карта сайту (Sitemap):
- **Головна сторінка (Home)**
  - Шапка з логотипом «PythonStart» та індикатором прогресу
  - Блок мотиваційного вітання
  - Каталог 4 навчальних тем:
    1. Змінні та типи даних
    2. Арифметичні операції
    3. Умовні оператори (if / elif / else)
    4. Цикли (for / while)
  - Підвал із даними команди EduTech Innovators
- **Екран теми (Topic View)**
  - Теоретична довідка з підсвіченими прикладами коду
  - Блок попередження про типові помилки («Зверніть увагу»)
  - Кнопка швидкого переходу до інтерактивної вправи
- **Екран практичної вправи (Interactive Quiz)**
  - Картка питання з формулюванням та фрагментом коду
  - Варіанти відповідей (вибір або поле введення)
  - Кнопка валідації «Перевірити»
  - Модальне вікно / підказка результату (Success / Error explanation)
- **Підсумковий екран (Score Summary)**
  - Радіальна шкала успішності (відсоток правильних відповідей)
  - Рекомендація та кнопки повернення

## 3. Колірна палітра та типографіка
### 3.1. Палітра (Design Tokens):
- **Primary Accent:** `#2563EB` (Royal Blue — основний колір кнопок, активних посилань);
- **Primary Hover:** `#1D4ED8` (темніший відтінок для наведення);
- **Success State:** `#16A34A` (зелений — правильна відповідь, схвалення);
- **Error State:** `#DC2626` (червоний — помилка у відповіді, попередження);
- **Warning / Notice:** `#F59E0B` (бурштиновий — підказки та зауваження);
- **Background Light:** `#F8FAFC` (м'який світло-сірий фон);
- **Card Background:** `#FFFFFF` (чистий білий для карток);
- **Text Main:** `#0F172A` (темно-графітовий, висока контрастність);
- **Text Muted:** `#64748B` (нейтральний сірий для другорядних підписів).

### 3.2. Шрифтова схема:
- Основний текст інтерфейсу: **Inter** / **Roboto**, без засічок, кеглі 14px, 16px, 20px, 28px;
- Приклади коду та термінал: **JetBrains Mono** / **Fira Code**, моноширинний, кегль 14px.

## 4. Стан компонентів (Interactive States)
- **Кнопка «Перевірити»:** Default (disabled до вибору відповіді) -> Active -> Hover -> Focus -> Loading.
- **Картка вибору відповіді:** Default (білий фон, тонка сіра рамка) -> Hover (блакитна рамка) -> Selected (синій акцент) -> Correct (зелена рамка + бейдж) -> Wrong (червона рамка + підказка).
