# Методичний паспорт шкільного проєкту «Навчальний тренажер PythonStart»

## 1. Загальні відомості
- **Назва освітнього продукту:** Інтерактивний тренажер з основ програмування «PythonStart»
- **Цільова навчальна аудиторія:** Здобувачі освіти 8–9 класів ЗЗСО (рівень базової середньої освіти)
- **Освітня галузь:** Інформатична (згідно з Державним стандартом базової середньої освіти)
- **Розробники:** Команда студентів спеціальності 014.09 «Середня освіта (Інформатика)» EduTech Innovators

## 2. Освітні цілі та очікувані результати навчання (за Модельними програмами МОН)
- **Знаннєвий компонент:** засвоєння понять змінної, динамічної типізації, пріоритету арифметичних дій, лінійних, розгалужених та циклічних алгоритмічних конструкцій.
- **Діяльнісний компонент:** формування вміння читати фрагменти коду мовою Python, прогнозувати результати виконання та виявляти логічні/синтаксичні помилки.
- **Ціннісний компонент:** формування мотивації до вивчення цифрових технологій через інтерактивну гейміфіковану самоперевірку.

## 3. Методичні рекомендації щодо впровадження у навчальний процес
- **Формат 1 (Інтерактивна розминка):** 5–7 хвилин на початку уроку інформатики для актуалізації опорних знань.
- **Формат 2 (Індивідуальна самоперевірка):** проходження блоку завдань на етапі закріплення нового матеріалу.
- **Формат 3 (Дистанційне/домашнє навчання):** можливість тренування зі смартфонів завдяки повній мобільній адаптивності.

## 4. Критерії та шкала оцінювання
- **90–100%:** Високий рівень (учень безпомилково розпізнає синтаксичні конструкції).
- **70–89%:** Достатній рівень (незначні помилки в пріоритетах операцій).
- **50–69%:** Середній рівень (потрібне додаткове опрацювання теоретичних карток).
- **Менше 50%:** Початковий рівень (потребує консультації вчителя).
