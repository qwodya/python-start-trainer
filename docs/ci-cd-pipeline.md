# Специфікація конвеєра безперервної інтеграції (CI/CD) у тренажері «PythonStart»

## 1. Конвеєр автоматизованого тестування (GitHub Actions)
У файлі `.github/workflows/ci.yml` налаштовано робочий процес (Workflow), що спрацьовує на кожну подію `push` та `pull_request` у головну гілку `main`.
Конвеєр автоматично:
1. Завантажує код на віртуальну машину Ubuntu (`actions/checkout@v4`);
2. Розгортає ізольоване середовище Node.js (`actions/setup-node@v4`);
3. Встановлює залежності (`npm ci`);
4. Запускає набір модульних тестів Vitest (`npm test`).

## 2. Правила захисту головної гілки (Branch Protection Rules)
Для гарантії стабільності релізу налаштовано інженерні обмеження для гілки `main`:
- Заборонено прямий пуш у `main` (лише через Pull Request);
- Обов'язкове успішне проходження перевірок CI (Automated Unit Testing);
- Мінімум одне схвалення під час Code Review перед злиттям.
