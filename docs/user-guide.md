# Інструкція користувача навчального тренажера «PythonStart»

## 1. Загальні відомості
Навчальний тренажер «PythonStart» призначений для учнів 8–9 класів ЗЗСО та студентів педагогічних коледжів/університетів, які розпочинають вивчення мови програмування Python. Застосунок працює безпосередньо у веббраузері (як на десктопних ПК, так і на смартфонах) без необхідності попереднього встановлення інтерпретаторів чи середовищ розробки.

## 2. Початок роботи
1. Відкрийте публічне посилання на тренажер: https://qwodya.github.io/python-start-trainer
2. На головній сторінці оберіть тему для навчання:
   - **«Змінні та типи даних»**
   - **«Арифметичні операції»**
   - **«Умовні оператори (if / elif / else)»**
   - **«Цикли (for / while)»**
3. Натисніть кнопку **«Вивчати тему»**.

## 3. Навчальний сценарій
- **Крок 1. Теоретична довідка:** прочитайте лаконічний конспект, зверніть увагу на відформатовані блоки коду та блок «⚠️ Зверніть увагу» з типовими синтаксичними помилками.
- **Крок 2. Інтерактивна вправа:** натисніть «Почати тренування →». Уважно прочитайте умову задачі та фрагмент коду, оберіть один із варіантів відповіді та натисніть «Перевірити відповідь».
- **Крок 3. Зворотний зв'язок:** система миттєво підтвердить правильність розв'язку або виведе детальне пояснення помилки.
- **Крок 4. Підсумок:** після завершення всіх питань ознайомтеся зі своїм балом та рекомендацією. Прогрес автоматично збережеться в браузері.
