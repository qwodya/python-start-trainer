# Протокол командної ретроспективи проєкту «PythonStart» (Start, Stop, Continue)

## 1. Загальний огляд
Команда EduTech Innovators підбила підсумки наскрізного циклу розробки навчального тренажера за гнучкою методологією Agile/Scrum.

## 2. Аналіз за категоріями:
### START (Що команді варто почати робити):
- Застосовувати парне програмування на етапі складної архітектурної інтеграції;
- Впроваджувати автоматизовані E2E-тести для перевірки дій користувача в браузері.

### STOP (Що команді варто припинити робити):
- Відкладати оформлення документації на завершальні етапи перед релізом;
- Працювати з великими комітами замість частих атомарних збережень.

### CONTINUE (Що спрацювало відмінно і слід продовжити):
- Дотримання дисципліни гілок Feature Branch Workflow та обов'язкового Code Review;
- Автоматичний прогін конвеєра CI в GitHub Actions перед кожним злиттям;
- Прозоре планування завдань на дошці GitHub Projects.
