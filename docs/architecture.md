# Архітектурна специфікація клієнтського вебзастосунку «PythonStart»

## 1. Загальний огляд архітектури
Застосунок побудовано за модульним принципом на базі чистих стандартів вебплатформи (Vanilla JavaScript ES6+, HTML5, CSS3) без перевантаження важкими зовнішніми фреймворками. Архітектура спирається на принцип єдиної відповідальності (Single Responsibility Principle) та патерн розділення стану, даних та представлення (State-Driven UI).

## 2. Структура модулів (src/js/)
- **`state.js` (Управління станом):** зберігає глобальний стан сесії (поточна обрана тема, поточний індекс вправи, кількість правильних відповідей, історія відповідей).
- **`topics.js` (Банк тем):** каталог тем курсу Python («Змінні», «Арифметика», «Умови», «Цикли») із метаданими.
- **`theory.js` (Банк теоретичних довідок):** навчальні конспекти, форматовані блоки коду та попередження про типові помилки.
- **`quiz.js` (Движок перевірки та бізнес-логіка):** алгоритми перевірки відповідей, очищення введених рядків, підрахунок відсотка успішності.
- **`ui.js` (Рендеринг інтерфейсу):** генерація HTML-розмітки, маніпуляція DOM-деревом, перемикання екранів, динамічна зміна класів стилів.
- **`app.js` (Головний контролер / Точка входу):** ініціалізація застосунку, підписка на події користувача, координація між модулями.

## 3. Діаграма потоку даних (Data Flow)
User Click -> app.js (Event Listener) -> quiz.js (Validate) -> state.js (Update State) -> ui.js (Render Screen).
