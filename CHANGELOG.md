# Журнал змін (Changelog) навчального тренажера «PythonStart»

Усі ключові зміни проєкту фіксуються відповідно до принципів семантичного версіонування (SemVer).

## [1.0.0] — 2026-11-21 (Офіційний реліз MVP)
### Додано (Added):
- Семантичний вебінтерфейс (HTML5 / CSS3) із повною підтримкою Flexbox та CSS Grid.
- Модульна архітектура JavaScript (ES6+): `state.js`, `topics.js`, `theory.js`, `quiz.js`, `ui.js`, `api.js`, `app.js`.
- Каталог навчальних тем та банк практичних завдань у форматі `data/topics.json`.
- Автоматизоване модульне тестування бізнес-логіки у фреймворку Vitest (100% покриття критичних функцій).
- Інтеграція зовнішнього REST API з асинхронним завантаженням та резервним режимом Fallback.
- Автоматизований CI-конвеєр у GitHub Actions (.github/workflows/ci.yml).
- Довготривале збереження прогресу учня у `localStorage`.
- Повна документація: специфікація вимог, UI/UX макети, посібник користувача та паспорт проєкту.
